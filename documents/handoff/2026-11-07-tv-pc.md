## Steps

1. Pull and restart.
   ```bash
   git pull
   docker compose up -d && docker compose restart romm
   ```
   If this machine runs under WSL2, run these inside the WSL distro where `~/romm` lives.

2. Copy the gitignored game files from i5-PC (LAN 192.168.68.66, user `david`).
   The TV PC needs ssh access to i5-PC; if that is not set up, ask David to run the
   rsync from i5-PC toward this machine instead, or use RomM's per-game Upload button
   in the browser (fine for wof.zip, slow for the 100 MB PS1 image).
   ```bash
   cd ~/romm
   rsync -av --progress david@192.168.68.66:/mnt/Samsung2TB/projects/romm/library/roms/psx/    library/roms/psx/
   rsync -av --progress david@192.168.68.66:/mnt/Samsung2TB/projects/romm/library/roms/arcade/ library/roms/arcade/
   ```
   Expected result: `library/roms/arcade/wof.zip` and
   `library/roms/psx/Metal Slug X (USA)/Metal Slug X (USA).{bin,cue}`.

3. PS1 BIOS. Ask David for `scph5501.bin` (US). Do not download one; it must come from
   hardware he owns or an emulator folder he already has. Place it at
   `library/bios/psx/scph5501.bin`. It is gitignored by the `*.bin` rule; never commit it.
   Without it the pcsx_rearmed core uses its HLE BIOS, which boots most games but can
   hang or break memory-card saves.

4. Verify in RomM (http://localhost:8080): Scan -> Scan. Confirm:
   - Warriors of Fate appears under Arcade and plays with mame2003_plus.
   - Metal Slug X appears under PlayStation. On the Play screen choose the BIOS under
     Firmware if step 3 is done, then play through the first stage and save.
   If an arcade set refuses to boot on mame2003_plus, try fbneo from the game's core
   selector before changing anything in config.yml.

5. Gamepad check on the TV. P1/P2 bindings for all cores are in `config/config.yml`
   (named EmulatorJS identifiers like BUTTON_1, DPAD_UP). If a controller maps wrong,
   fix it there, `docker compose restart romm`, retest, then commit per CLAUDE.md.

6. Close out: delete this file and its CLAUDE.md pointer, commit on `adding_feature_dl`,
   fast-forward `main`, push both.

- Do not force-push `main`.
- Do not touch `assets/users/<id>/` folders that are not this machine's user.
